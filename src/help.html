Using the IPA Library

A quick guide to transcribing with the International Phonetic Alphabet in Word. We hope it saves you time, whether you're writing up an assessment, preparing therapy materials, or studying phonetics.

Open the library

In Word, choose the JBC Speech tab, then IPA Library. The same button hides it again. The library stays open while you type and insert symbols.

Insert symbols

  • Click in your document, then click a symbol. If text is selected, the symbol replaces it.
  • The cursor moves past each symbol, so you can click several in a row to build a transcription.
  • Diacritics attach to the letter before them, so put the cursor just after the base letter first. The dotted circle (◌) only shows where the mark goes; it's never inserted.
  • Tie bars: insert one between the two letters it joins, or pick a ready-made affricate such as t͡ʃ.

List and Chart views

Use the List | Chart switch at the top. List groups the symbols by category. Chart lays them out like the IPA chart:

  • consonants by place and manner, voiceless on the left and voiced on the right;
  • shaded cells for sounds judged impossible;
  • vowels on the vowel chart.

In a narrow pane the consonant table is split into four parts; widen the pane to see it whole. Your choice is remembered.

Search and jump

Open Search & audio to search by symbol, name (for example "voiceless velar"), category, or Unicode code (for example "U+0259"). Use Jump to to reach a section.

Listen

Choose a voice: J. Esling or J. House. Symbols marked ♪ have a recording. Shift-click one to hear it without inserting anything, or press Shift+Enter or Shift+Space from the keyboard. Stop audio stops playback. Some recordings demonstrate the sound in syllables or words.

Fonts

Symbols take on your document's font. For the clearest IPA, use a font designed for it, such as Doulos SIL or Charis SIL (free from SIL International).

If the library doesn't open

  • No JBC Speech tab? Open the Start menu and choose JBC Speech (online) or Open JBC Speech in Word. Or in Word, go to Home → Add-ins → More Add-ins → My Add-ins → Developer Add-ins → JBC Speech → Add.
  • Installed on this PC: open the Start menu → JBC Speech → Start JBC Speech server, then reopen the library.
  • Online version: check your internet connection.
  • Either way, Word needs an internet connection when the library opens, because Microsoft's add-in code loads from the web.

This is a work in progress. It was made for speech-language pathologists (SLPs) and anyone else who writes IPA, and we hope it's genuinely useful to you. If something would make it better, or something isn't working, we'd love to hear about it.
