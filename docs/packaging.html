Packaging for her PC A double-click installer, everything local · Windows · 26 Nov 2026

One zip file (~38 MB). She unzips it, closes Word and double-clicks Install JBC Speech. Windows asks one question about a certificate (she clicks Yes), and the JBC Speech tab appears in Word. Nothing is hosted online, she doesn't need Node, and no admin rights are required.

Why there's a server at all: a Word add-in pane is a little web page, and Word only opens it from an https:// address. So "fully local" means a tiny web server on her PC, plus a certificate that Windows trusts for localhost. Microsoft's add-in library (Office.js) still loads from the web, so Word needs internet when the pane opens.

2What the installer does (click a step)

  • Check Word build ≥ 15202 (version 2205)

    Reads VersionToReport from Office's Click-to-Run settings. If Word is too old it stops and says how to update. It also waits until Word is closed.

  • Copy files → %LOCALAPPDATA%\JBC Speech

    Stops an old server if one is running, replaces src, scripts and node, and keeps the certificate and log. Removes the "downloaded from internet" flag from the files.

  • Certificate one Windows prompt: click Yes

    Creates a localhost certificate in her personal store and exports it for the server with a random passphrase. Then adds it to her trusted roots, which is when Windows asks. If she clicks No, the installer explains and stops. On reinstall the same certificate is reused, so there's no second prompt.

  • Start the server Startup shortcut + start now

    Shortcuts in Startup and the Start menu run node.exe server.mjs --config jbc-speech.json --background. The launcher exits straight away and leaves a hidden server running, unless one is already running. The installer then fetches the page over HTTPS to prove the certificate is trusted.

  • Open the welcome document this is what adds the tab

    Lesson from the first real install: the registry entry only makes Word list the add-in under Home → Add-ins → My Add-ins → Developer Add-ins, so no tab appeared. The installer now builds Welcome to JBC Speech.docx, which references the add-in, and opens it. Word adds the add-in, the JBC Speech tab appears, and the library opens on the right. A Start menu shortcut reopens the document if the tab ever goes missing. Still no admin rights.

  • Register Word + Settings → Apps

    Adds one value under WEF\Developer (add-in ID → manifest path), the same thing npm run sideload does. Also adds an Apps entry so she can uninstall it like any program.

4Plan B: hosted on GitHub Pages

A work PC managed by IT may block the installer: restricted PowerShell, programs blocked in user folders, certificate rules, or add-in policies. Installing a background server there needs IT's OK anyway. So the same pane is also published to GitHub Pages, and IT only has to deploy one manifest URL.

Online installer personal PC, hosted copy · 6 KB

Download …github.io/jbc_speech/downloads/JBC-Speech-online.zip from the landing page and double-click. It only saves the manifest and adds the one Word registry entry plus a Settings → Apps entry. No server, no certificate, no Node. The pane updates itself with every push.

Why the installers aren't code-signed: the "Windows protected your PC" warning comes from the mark Windows puts on downloads. A self-signed certificate wouldn't be trusted on her PC either, and .cmd files can't be signed at all. So the instructions say to right-click the zip → Properties → Unblock before extracting, and the warning never appears. Paid signing (about $10 a month) only makes sense if the installer becomes an .exe.

For IT: docs/IT-deployment.md is a one-page request with the manifest URL, admin-center steps, permissions and data handling, and the audio license.
