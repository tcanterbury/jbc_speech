Chart view

The chart on your classroom wall, inside Word.

Voiceless on the left, voiced on the right, shaded cells where sounds are judged impossible: the layout follows the International Phonetic Association's 2020 chart. In a narrow pane the table splits into Lips, Tongue tip, Tongue body and Throat. Widen it and the whole chart appears.

Get started

Add it to Word

Choose the way that fits your computer. Afterwards, open the JBC Speech tab and click IPA Library.

Easiest Your own Windows PC small installer
  1. Download the installer (a few KB).
  2. Right-click the zip → Properties → tick Unblock → OK. This stops Windows warning about a downloaded file.
  3. Right-click the zip → Extract All.
  4. Close Word, then double-click Install JBC Speech (online).cmd.
  5. Word opens a short welcome document and adds the JBC Speech tab. If Word asks to trust the add-in, choose Yes.

No tab? Start menu → JBC Speech (online) opens the welcome document again. Or in Word: Home → Add-ins → More Add-ins → My Add-ins → Developer Add-ins → JBC Speech → Add.

To remove it: Settings → Apps → Installed apps → JBC Speech (online) → … → Uninstall.

Work Work PC managed by IT IT adds it for you

Ask IT to deploy this manifest from the Microsoft 365 admin center (Settings → Integrated apps → Upload custom apps → Office Add-in):

{{BASE_URL}}/manifest.xml

Nothing is installed on the PC. The add-in only inserts the symbols you click, and sends nothing anywhere.

Manual Word on Windows, without an installer shared folder
  1. Save manifest.xml into a folder of its own.
  2. Share the folder: right-click → Properties → Sharing → Share. Note its network path, for example \\PC-NAME\folder.
  3. In Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs.
  4. Paste the path into Catalog Url → Add catalog → tick Show in Menu → OK, and restart Word.
  5. Home → Add-ins → More Add-ins → Shared Folder → JBC Speech → Add.
Web Word on the web browser
  1. Save manifest.xml.
  2. Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in, and choose the file.

Microsoft intends this for testing; the add-in can disappear when browser data is cleared.

Needs Microsoft 365 Word (version 2205 or later) or Word 2024. Menu labels vary a little between versions. Full help →
